# Ti-6Al-4V 밀링 공구 마모 판단 운영 매뉴얼

이 문서는 대회용 AI Agent의 공구 상태 판단에 사용하는 프로젝트 운영 매뉴얼이다.
제조사 공식 공구 수명 기준을 대체하지 않는다.

## 공구 마모 판단 순서

1. 먼저 진동, 소리, 힘 센서의 데이터 무결성을 확인한다.

Dropout, 장시간 고정(stuck), 심각한 결측 또는 센서 자체 이상이
확인되면 공구 마모 판단보다 SENSOR_FAULT 판단을 우선한다.

2. 센서 무결성이 정상인 경우 정상 공구로 측정한 기준 가공 데이터와
현재 가공 데이터를 비교한다.

3. 공구 마모가 진행되면 동일하거나 유사한 절삭 조건에서
절삭력 증가, Force 변동 증가, 진동 증가와 같은 징후가
지속적으로 나타날 수 있다.

4. 단일 순간 spike만으로 공구 마모를 확정하지 않는다.

여러 연속 가공 Window에서 지속되는 변화와
여러 Force 축의 동시 증가를 우선한다.

5. 프로젝트 운영 기준에서는 정상 Force baseline과 비교하여
Fx/Fy/Fz 중 최소 2개 축의 변동량이 정상 중앙값의 약 1.8배 이상이면서
정상 95% 범위를 충분히 초과하고,
Force resultant RMS가 정상 중앙값의 약 1.25배 이상으로 지속될 경우
공구 마모 징후로 판단한다.

6. 위 조건을 만족하고 센서 이상이 배제된 경우
Agent는 TOOL_WEAR를 반환하고
공정 HOLD 및 공구 점검/교체를 권고한다.

## 안전 원칙

센서 고장과 공구 마모가 동시에 의심되는 경우
SENSOR_FAULT를 우선 처리한다.

센서 신뢰성이 확보되지 않은 상태에서는
공구 상태를 확정하지 않는다.
